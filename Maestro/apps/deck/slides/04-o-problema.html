// o botão existe... mas o app ainda está renderizando

await driver.pause(3000);   // splash
await loginBtn.click();
await driver.pause(5000);   // chamada de API

// 10 segundos parados POR TESTE.
// 200 testes = 33 minutos só dormindo.
// E se a rede demorar 5,1s? Falha assim mesmo.
# um setup típico de Appium antes do 1º teste
npm i -D webdriverio appium
appium driver install uiautomator2
appium driver install xcuitest
# + Appium Server rodando numa porta
# + capabilities por plataforma
# + Xcode CLI tools, Android SDK, JDK certo
# + no Detox: build nativo dedicado do app

→ horas de configuração antes da 1ª asserção
// Detox: a ferramenta é compilada JUNTO com o app
// android/app/build.gradle
androidTestImplementation('com.wix:detox:+')

// e no package.json, um binário só para teste:
"build": "detox build -c ios.sim.debug"

// Consequência: subiu o RN 0.7x → Xcode novo →
// versão do Detox precisa acompanhar.
→ a suíte de testes vira mais um projeto para manter
