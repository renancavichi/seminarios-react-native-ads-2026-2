Ato 04 · honestidade técnica

O que o Maestro não faz bem

Ele testa o app inteiro, nunca a peça

Não existe "rodar só essa função" nem medir cobertura de código. Se o cálculo do frete estiver errado, o Maestro só avisa que o valor na tela ficou diferente do esperado — não aponta a linha.

Como conviver: Jest embaixo, Maestro em cima. São complementares, não concorrentes.

Acentuação e emoji quebram no Android

É uma limitação conhecida e documentada: no Android o comando de digitação só suporta caracteres ASCII. Para um app brasileiro, digitar "João" num campo de nome é um problema real.

Como conviver: use dados de teste sem acento, ou preencha o campo via clipboard (setClipboard + pasteText).

Conteúdo dentro de WebView nem sempre aparece

A árvore de acessibilidade nativa às vezes não expõe o que está renderizado dentro de uma WebView — e o Maestro simplesmente não enxerga o botão.

Como conviver: no Android, declarar androidWebViewHierarchy: devtools no topo do flow faz o Maestro inspecionar a página pelo Chrome DevTools. Fluxo híbrido pesado ainda é território de ferramenta web.

Ele espera bem, mas no escuro

O Maestro não sabe o que a thread JavaScript do React Native está fazendo. Ele observa a tela, espera assentar e tenta de novo. O Detox, por ser caixa-cinza, sabe quando o app terminou de trabalhar.

Consequência: em apps com animação longa ou polling constante, ainda pode sobrar algum caso raro de instabilidade. Aí você paga com extendedWaitUntil.

Não é 100% "zero setup"

O CLI roda na JVM: versões de Java muito novas ou muito antigas dão problema — a recomendação oficial é Java 17 ou 21. Antes de cada execução ele instala um app-driver no aparelho, e dispositivos corporativos travados (MDM, fintech, POS) podem bloquear essa instalação. Nesses casos, não há solução: é usar outro aparelho.

E iOS continua exigindo macOS com Xcode.

Detalhes chatos do iOS

O hideKeyboard é instável porque o iOS não oferece API nativa para esconder o teclado — o Maestro simula um gesto. E listas com paginação (UITableView) podem se comportar de forma estranha por um bug do próprio XCTest, que o Maestro usa por baixo.

Como conviver: tocar numa área neutra da tela no lugar de esconder o teclado.

Local é grátis; paralelo, não

CLI e Studio são open source. Rodar centenas de flows em paralelo, em vários modelos de aparelho, é serviço pago — com limite recomendado de cerca de 20 minutos por execução.

Os comandos com IA (assertWithAI) também dependem de chave de API e, por natureza, não são determinísticos.
