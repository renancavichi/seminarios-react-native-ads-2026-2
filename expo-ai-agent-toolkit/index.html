05 / 13 Parte 1 · O problema

Gerar código não é o mesmo que verificar o app

A tela compila sem erros. Mas quando o cliente toca em Telefone para digitar, o teclado sobe e tampa o próprio campo onde ele está escrevendo — fechá-lo com “Pronto” não resolve, porque o teclado precisa ficar aberto para digitar!

app/reserva.tsx 0 erros de TypeScript / Lint 
// ⚠ View fixa sem KeyboardAvoidingView nem ScrollView
<View style={styles.container}>
  <TextInput placeholder="Nome do cliente" />
  <TextInput placeholder="E-mail" />
  <TextInput placeholder="Telefone" /> // <- fica atrás do teclado!
  <Pressable onPress={handleConfirmar}>Confirmar reserva</Pressable>
</View>
Por que esse erro acontece e passa despercebido?
  • No código não existe teclado virtual: no desktop ou no JSX estático, todos os campos aparecem inteiros; no celular, o teclado ocupa ~45% da tela e não há rolagem automática.
  • Testes unitários também passam: ferramentas como fireEvent.changeText escrevem direto no componente JS, sem verificar se o usuário enxerga o que digita.

06 / 13 Parte 2 · A solução e a tecnologia

Conhecendo o Expo AI Agent Toolkit

O Expo executa e exibe o app; o Toolkit não é necessário para rodar o projeto — ele dá à IA ferramentas para interagir, inspecionar a interface e automatizar parte dos testes.

Cérebro

Agente de IA

Claude Code, Codex, Cursor. Interpreta instruções, planeja e edita código.

MCP / CLI
⇄
Olhos & Mãos

Toolkit Especializado

Inspeciona árvore de UI, toca botões, preenche campos, tira screenshots e lê logs.

Ações reais
⇄
Execução

App no Emulador

Android Emulator, iOS Simulator ou dispositivo em execução (local ou EAS).

agent-device Callstack · Principal na demo

CLI focada em agentes para controlar apps iOS/Android (local ou EAS Simulators): árvore de acessibilidade (snapshot -i), toque (press), texto (fill), screenshots e logs.

Argent Software Mansion · Alternativa

Toolkit open-source conectado via MCP para Android Emulator e iOS Simulator, com controle de fluxo, inspeção da árvore React, logs e profiling.

Obs.: agent-device e Argent são opções alternativas, não etapas obrigatórias.
MCP (Model Context Protocol) Protocolo

Padrão que conecta o modelo/agente a ferramentas e contexto externos (ex.: servidor MCP do Expo ou do Argent).

Expo Skills Conhecimento (SKILL.md)

Instruções declarativas que ensinam boas práticas do Expo ao agente. Não é MCP e não controla o dispositivo sozinho.

07 / 13 Parte 2 · A solução e a tecnologia

Como usar na prática: onde o app roda?

O agente de IA (Codex, Claude Code, Cursor) envia comandos pelo agent-device para controlar o app rodando em 3 ambientes:

🖥
Opção 1 · Local

Emulador ou Simulador

Roda direto no seu PC com Android Studio Emulator ou iOS Simulator (Xcode no macOS).

npx agent-device open com.app --platform android Melhor para: iterar rápido enquanto desenvolve na máquina.
☁
Opção 2 · Nuvem (EAS)

Expo Simulators

Simuladores Android e iOS rodando na nuvem da Expo — sem precisar de emulador pesado ou de Mac para testar iOS.

eas simulator:exec agent-device snapshot -i Melhor para: Windows testando iOS e testes automáticos em CI/CD.
📱
Opção 3 · Aparelho Real

Celular Físico (USB)

Aparelho Android (ADB) ou iPhone conectado ao computador — suportado pelo agent-device (além de web/TV).

npx agent-device logs start --platform ios Melhor para: validar gestos reais, sensores e performance real.
Importante Expo Go: ótimo para o dev visualizar manualmente, mas toolkits como agent-device / Argent controlam builds nativos / simuladores em execução.
07-2 Parte 2 · A solução e a tecnologia

Na prática: instalando o agent-device

Passo a passo para deixar o agent-device pronto no projeto e conectado ao seu agente de IA.

1. Instalação & Skill do Agente Terminal
  • Instale a CLI (ou use via npx): disponível globalmente ou como dependência dev no projeto.
  • Adicione a Skill oficial: ensina Claude Code, Cursor ou Codex a usar os comandos certos.
  • Confira o dispositivo: garanta um emulador aberto (adb devices no Android ou Simulator no macOS).
Setup inicial CLI + Skill 
# 1. Instalar a CLI (ou rodar direto com npx)
npm install -g agent-device

# 2. Adicionar a skill oficial ao seu agente
npx skills add callstackincubator/agent-device
2. Build nativo & primeiro teste Emulador / USB
  • Suba um build nativo: o agent-device controla builds nativos de desenvolvimento (não o Expo Go).
  • Abra e inspecione: o agente usa open e snapshot -i para mapear botões e campos (@e1, @e2...).
Execução prática Android / iOS 
# 3. Subir o app no emulador local
npx expo run:android

# 4. Abrir no agent-device e listar elementos
npx agent-device open com.app --platform android
npx agent-device snapshot -i
Dica Sem emulador local? Rode na nuvem da Expo com eas simulator:exec agent-device snapshot -i (ideal para testar iOS no Windows ou em CI/CD).

Outras alternativas: conhecendo o Argent

          

          
O agent-device não é a única opção: a Software Mansion mantém o Argent, outra alternativa open-source do ecossistema Expo/React Native.

        


        

          

            

              O que é o Argent?
              Software Mansion · MCP
            

            
    
              
  • Conexão direta via MCP: integra com Claude Code, Cursor e Codex através de servidor MCP dedicado.
    • 
              
  • Foco em emuladores: projetado para Android Emulator e iOS Simulator (locais ou via eas simulator:exec --type argent).
    • 
              
  • Além de cliques e texto: permite inspecionar a árvore de componentes React, ler logs e fazer profiling de performance (renders lentos).
    • 
            

            

              

                Inicialização via CLI
                Open-source
              

              
# Instala e registra o servidor MCP no editor
npx @swmansion/argent init

            

          


          

            

              
                

                  Aspecto
                  agent-device (Callstack)
                  Argent (Software Mansion)
                

              
              
                

                  Integração
                  CLI enxuta para agentes + EAS Simulators
                  Servidor MCP + wizard argent init
                

                

                  Alvos
                  iOS, Android, dispositivos físicos, web/TV
                  Android Emulator e iOS Simulator
                

                

                  Destaque
                  snapshot -i leve e econômico em tokens
                  Inspeção da árvore React e profiling
                

                

                  Relação
                  Alternativas independentes — você escolhe uma conforme o fluxo do projeto (não são etapas obrigatórias).

              Parte 3 · Quando usar
            

            
Quando usar o Argent?

          

          
Escolha o Argent quando o agente precisar de diagnóstico profundo em React Native e integração direta via MCP em emuladores.

        


        

          

            

              Cenários ideais para o Argent
              Quando escolher
            

            
    
              
  • Debug de performance e renders: quando há lentidão na interface e o agente precisa inspecionar a árvore de componentes React e fazer profiling.
    • 
              
  • Fluxo nativo via MCP: quando você já usa Claude Code, Cursor ou Codex com servidores MCP e quer configurar rápido com npx @swmansion/argent init.
    • 
              
  • Foco em emuladores: ideal para testes no Android Emulator e iOS Simulator (locais ou na nuvem com eas simulator:exec --type argent).
    • 
              
  • UI + logs do aplicativo: quando não basta tocar na tela e o agente precisa cruzar o que vê com logs internos.
    • 
            

          


          

            

              Quando preferir o agent-device?
              Critério prático
            

            
    
              
  • Celular físico por USB: quando é necessário validar gestos, teclado e comportamento em aparelhos reais (além de web e TV).
    • 
              
  • Menor consumo de tokens: o snapshot -i gera uma lista enxuta de elementos interativos para fluxos E2E longos.
    • 
              
  • Automação via CLI: quando você prefere comandos diretos de terminal em scripts e CI/CD.
    • 
            

            

              Regra rápida: use agent-device para navegação E2E leve e aparelhos reais; escolha o Argent para investigar componentes React, logs e performance via MCP.
