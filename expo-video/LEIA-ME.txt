COMO USAR (resumo)

1) Extraia este zip (botão direito > Extrair tudo).
2) Abra o VS Code > Arquivo > Abrir Pasta... e escolha a pasta extraída (a que tem App.tsx e package.json).
3) Abra o terminal do VS Code (Ctrl + ') e rode, UM DE CADA VEZ:

     npm install expo@latest

     npx expo install react react-native expo-video expo-status-bar react-dom react-native-web @expo/metro-runtime typescript @types/react

     npx expo start -c

4) Quando aparecer o menu, aperte  w  para abrir no navegador. Setas do teclado trocam de slide.

Os vídeos de cada exemplo ficam em assets/deck/videos/ (troque os arquivos mantendo os mesmos nomes).
