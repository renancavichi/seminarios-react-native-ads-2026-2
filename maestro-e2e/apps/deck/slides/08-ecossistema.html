Ato 02 · as peças

Quatro portas de entrada, um motor só

grátis

Studio

App de desktop que espelha a tela do aparelho. Você clica no elemento e ele escreve o comando YAML para você. É a porta de entrada de quem nunca testou nada.

grátis · open source

CLI

O motor. Interpreta os arquivos, roda no terminal, no modo contínuo e dentro do CI. É o que você vai usar no trabalho.

pago

Cloud

Sobe o app e os flows para rodarem em paralelo em dezenas de aparelhos virtuais hospedados. Integra com GitHub Actions, Bitrise, CircleCI.

novo

MCP Server

Expõe o Maestro para agentes de IA: o seu assistente de código consegue escrever, rodar e depurar o teste sozinho no emulador.

fluxo de trabalho real
# 1. desenha o teste clicando na tela
maestro studio

# 2. roda localmente enquanto desenvolve
maestro test flows/login.yaml

# 3. modo contínuo: salvou, rodou de novo
maestro test --continuous flows/login.yaml

# 4. no pull request, em paralelo, na nuvem
maestro cloud --app-file app.apk flows/

Por que isso importa para o estudante

O que é open source e gratuito — CLI e Studio — já cobre 100% do que você precisa no TCC, no estágio e num projeto pequeno. A parte paga resolve escala: rodar 300 testes em 12 minutos num time grande.

Analogia: o CLI é o seu violão. A Cloud é alugar a orquestra sinfônica inteira para tocar a mesma partitura ao mesmo tempo.
