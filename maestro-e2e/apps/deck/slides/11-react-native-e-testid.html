A única "integração" que existe

O testID do React Native vira Resource ID no Android e accessibilityIdentifier no iOS. O Maestro lê esse valor pelo seletor id.

Dá para mirar pelo texto visível (tapOn: "Entrar"), mas isso quebra quando alguém traduz o app ou troca o rótulo. testID é a prática recomendada.
