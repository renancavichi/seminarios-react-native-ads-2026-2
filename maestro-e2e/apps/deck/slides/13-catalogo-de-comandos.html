O poder de estar fora do app

GPS, modo avião, modo escuro, permissões, notificação, orientação da tela, relógio do sistema, galeria de fotos. Nenhuma ferramenta de caixa-branca consegue tocar nisso.

launchApp
# abre o app do zero, apagando dados
- launchApp:
    appId: "com.exemplo.app"
    clearState: true
    permissions:
      camera: allow
      location: deny

# por que importa: teste que depende do
# estado anterior é teste que vai falhar
# na terça-feira sem ninguém entender.
- tapOn: "Entrar"

- tapOn:
    id: "btn_menu"
    repeat: 3
    delay: 300

# variações: doubleTapOn, longPressOn
- longPressOn: "Mensagem antiga"

# o tapOn já espera o elemento aparecer:
# não precisa de wait antes.
- tapOn:
    id: "email_input"
- inputText: "ana@empresa.com"

# apagar antes de digitar
- eraseText
- inputText: "${EMAIL}"
- hideKeyboard

# ⚠ no Android: só ASCII.
# "João" e emoji não entram (bug conhecido)
# a asserção: o teste só passa se isso for verdade
- assertVisible: "Compra aprovada"

- assertNotVisible: "Erro"

- assertTrue: "${output.total > 0}"

# regressão visual: compara com um print salvo
- assertScreenshot: "tela_home"

# assertVisible tem retry embutido:
# ele insiste antes de reprovar.
# rola até achar — como um humano faria
- scrollUntilVisible:
    element:
      text: "Termos de uso"
    direction: DOWN
    timeout: 20000
    speed: 40

# compare com a alternativa em outras libs:
# calcular offset em pixel e torcer.
# A doc chama isso de comando "idiomático".
- swipe:
    direction: LEFT      # carrossel

- swipe:
    from:
      id: "item_lista"
    direction: RIGHT     # arrastar p/ excluir

- swipe:
    start: "50%, 80%"
    end: "50%, 20%"
# na maioria dos casos você NÃO precisa esperar.
# quando precisa (upload, processamento):
- extendedWaitUntil:
    visible: "Relatório pronto"
    timeout: 60000

- waitForAnimationToEnd:
    timeout: 5000

# repare: espera por CONDIÇÃO, não por tempo.
- takeScreenshot: "01-tela-login"
